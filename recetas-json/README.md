# Archivo personal de recetas JSON

Esta carpeta conserva, dentro del proyecto, los lotes de recetas generados para
uso personal. No forma parte de la base activa de la aplicación y su contenido
no se carga ni se importa automáticamente.

## Nutriloca

- `nutriloca/recetas-restantes-nutriloca.json`: lote de 102 recetas.
- `nutriloca/granola-de-lenteja-nutriloca.json`: receta individual.

Cuando se quiera sumar alguna de estas recetas a la aplicación, se puede usar
el botón **Importar JSON** y pasar por la revisión habitual de duplicados.
